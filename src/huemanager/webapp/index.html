Préparer la migration

1. Capturer la sélection

À faire avant toute suppression. Le snapshot persistant contient les identifiants source, pièces, scènes, règles, automatisations et dépendances nécessaires à une reprise ultérieure.

2. Dépendances hors périmètre

Aucune analyse effectuée.

3. Libérer les appareils du Bridge source

Opération destructive. HueManager supprime uniquement les appareils physiques de la sélection, après sauvegarde du snapshot. L’opération peut être relancée : les appareils déjà absents sont ignorés.

4. Détecter sur le Bridge destination

Si certains appareils ne remontent pas, tu peux les éteindre/rallumer ou les réinitialiser puis relancer la recherche. Le snapshot reste conservé.

5. Vérifier le remapping 

        

        

          6. Restaurer la configuration
          
Le restore normal n’est autorisé que lorsque tous les appareils requis sont remappés. Le restore forcé ignore les appareils définitivement absents et élague les scènes/règles/automatisations qui les référencent ; aucun identifiant cible n’est inventé.
